# 22位评委资料深化：2026-10-15

用户要求继续深化全部22位的研究，保留原有五种模式与评审流程。目标是补充每位至少一份新的实质正文，优先解决个人档案已列的阶段／作品／教学／实际评审缺口；若不能取得可靠正文，明确记录未解决项，不把名录或重复转载计作新增深度。

流程：固定四组覆盖22席的同输入场景 → 保存v0.1.0基线 → 独立研究并暂存原创摘要 → 人工核对原文与声明映射 → 合入档案 → 同输入复测 → 更新版本、验证与交付包。基线诚实保留不等于失败，不会伪造改善。

任务分区：十位摄影家的阶段与作品；教授前五位；教授后五位；两位批评家的具体批评实践。各区仅写自己的研究暂存文件，主维护者整合来源和编号，避免并发修改同一JSON。

新增记录沿用作者、机构、原URL、发布日期／访问日、章节或页码、实际读取范围及F/I/R映射。作品图像有实际查看才登记，不以文本提取或图注声称目视；不存入未获准的原作图像和全文。

行为改变须有相同输入的前后例，保留合理分歧；文字澄清与实质规则改变分别记录。现有0.1.0压缩包保留，深化版另行打包。

## 核查中保留的区别

- 森山Aperture网页是2020再刊，访谈首刊为2011；不据页面年份构造其彩色转折时间。
- 童暦馆方给出1955–70拍摄、1971结集；不是把全部植田作品归成沙丘演出。
- 圆井对谈中本人、伊藤及本雅明引文分别处理；对谈页与展览页的展期差异不擅自消除。
- 西垣论文只细读指定理论段；没有借此声称读完12页全部历史论证。
- 胜又Remains出版社英文为伊藤俊治寄稿的编辑节选，不作摄影家自述；WAR REQUIEM II为タカザワケンジ署名解释。
- JPS会报p.35的饭泽段跨栏；没有把野町或清水的评审标准移入其档案。PDF页图实际查看只证明版面归属，不等同查看所有获奖作品。
- 本轮没有新增作品目视。作品视觉覆盖仍以原有十位摄影家日志为准，未将文字配图说明升级为亲见。
