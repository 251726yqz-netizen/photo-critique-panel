# 中文报告规范：有立场的批评

## 材料与开场

开头先给一句能被读者检验的总体判断，不以“很有氛围、值得继续”搪塞。随后登记模式、席位、图片编号与顺序、实际查看范围、作者提供的信息及影响判断的未知项。一次说明这是基于公开资料与作者推导的AI分析，不是真人参与或人格还原。

## 每席是一段论证，不是一张填空表

先读取该席档案的I/R与评审立场卡。正文自然展开以下论证关系，不要求固定段落顺序、相同句式或小标题：

每席的核心是：**对当前作品的判断、可见证据、它如何影响观看、为什么这一视角在意。** 对关键争议再充分展开另一读法、取舍与改变判断的条件；其他席位不必凑齐同一个六步结构。

论述节奏来自个人档案：感官相遇可以从一个刺眼细节切入，观念分析可以先拆一个矛盾，材料视角可以持续近看一处表面，教学视角可以先追问再用画面回答。它们都要论证，但不必以同样句序或相同标签出现。“本席认为／另一读法／行动／收益／代价”不作为逐席复读的文案；一个关键取舍已讲透时，综合段可直接引用而不重复。

- 判断须能争论，例如某处留白维持了尺度、某一转场提前结束了叙述。证据写P编号、位置与具体关系；图像不可读时不构造观察。
- 详细理由应让读者看到“为什么”：哪项细节使注意停留或断裂，什么被压住、什么被显露，为什么这影响当前表达。详细不等于更多形容词或未经依据的心理故事。
- 批评落到作者可以选择的决定。可以直说“这部分目前不成立”“标题在替照片承担论证”，但继续给证据；支持明确时也要直接肯定。没有问题不制造问题，没有适用材料不凑评论。
- 最重要的建议写出代价。裁切可能集中关系也可能失去身体位置，降低亮部可能显露细节也可能削弱光感；每项取舍应解释为何此刻值得或不值得。
- 每席附本次实际使用的档案I/R编号、来源ID和原始链接；机构解释注明归属。立场卡的发言节奏和追问是技能设计，不作人物引语。

全选按registry顺序覆盖10摄影家、2批评家、10教学视角。约200–350中文字是适用席位的参考而非下限；核心冲突可更长，不适用者几句即可。材料登记里已经说明的未知，不逐席重述，除非它正阻断某项判断。用户要详细时可分批，但须列出完成／待评名单并继续；不以字数达标代替完整论证。用户明确要简短则优先简短，保留判断与关键证据。

教授的研究方法只在相符题材使用；跨题材转译明确标注。单张可以因偶然成立，不因缺少系列便判失败；没有作者主张时不要求所有风景都承担社会史、商业任务或学术问题。

## 分歧必须有实际后果

综合实际成立的议题，通常至多2–3项；只有一项就只列一项，没有分歧就直说。写清哪些席位建议保留、哪些建议改变，各自采用什么标准。只有实际不同的结论才列为分歧；相同结论可以有不同依据。资料不足是保留，不冒充相反意见。

给出条件选择：以快速识别为目标可接受什么损失，以缓慢观看为目标为什么值得保留。不要用多数票或统一“折中调一调”抹去不同标准；主报告可以明确推荐保留某个选择。

## 三项优先行动

每项说明：当前机会／问题 → 具体动作或保留 → 预期收益与代价 → 可观察的复核条件 → 对应席位。只针对当前材料；练习用于验证判断，不延后给出判断。少于三项可靠行动时少列，不凑项。没有必要时不要求修改照片或扩充项目。

## 申请附录

独立列出官方提交要求：学校、课程、年度、类别、条款位置、核查日期、来源、材料满足／缺失／未核实。艺术批评可以直接，招生事实仍要按当年官方材料逐项核查；强烈语气不增加录取预测的可信度。

## 来源与覆盖说明

仅列实际使用的来源，优先在各席紧凑标注而非反复插入免责声明。末尾一次说明资料库的历史阅读与本次重查、未读原作及已评／待评范围。保存报告仅在用户要求时进行，不自动上传照片或评片。
