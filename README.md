# 日本写真评片 · Photo Critique Panel

版本：0.2.0。资料初次核查：2026-10-14；22位资料深化：2026-10-15（Asia/Tokyo）。

以10位摄影家、2位批评家、10位教授的公开资料提供中文评片。支持单张、组照、作品集、本科及修士申请指导，默认22个视角分别评论、不评分，最后呈现分歧和行动建议。

这是 **有来源的 AI 分析技能**。它不是本人评语、学校授权工具、模型训练成果或录取预测。原始事实、来源理念与应用性推导分别标记 F、I、R。

## 使用

将照片附在对话中或提供可读取的本地文件，然后调用：

```text
请使用 $photo-critique-panel 评价这张照片，按22个视角给出评论和建议。
```

```text
请使用 $photo-critique-panel，将P01至P08按当前顺序作为一组照片评价。
只用川内伦子、山本昌男、饭泽耕太郎和吉川直哉。
先指出每张的作用，再给出一套重排建议并解释分歧。
```

```text
请使用 $photo-critique-panel 审阅我的修士申请作品集。
目标学校、正式课程、入学年度、选拔类别如下……
附上作品集、创作陈述、研究计划和官方募集要项。
请分别评价作品表达和提交要求，列出未核实的事项。
```

没有照片时技能会列出所需材料，不产生假评片。没有目标学校／类别时仍可做一般作品指导。

## 安装到 Codex

本仓库根目录就是技能目录。下载／克隆后，将整个目录命名为 `photo-critique-panel` 并复制到 `${CODEX_HOME:-$HOME/.codex}/skills/` 下。默认完整路径为 `~/.codex/skills/photo-critique-panel/SKILL.md`。

安装目标存在时先比较和备份，不覆盖自定义档案。打开新对话检查技能是否出现，显式使用 `$photo-critique-panel` 调用。界面元数据位于 [agents/openai.yaml](agents/openai.yaml)。

也可在当前对话直接要求读取本目录 [SKILL.md](SKILL.md)；这属于本地文件调用，不能当作已经完成自动发现／安装。其他支持 Markdown 技能的平台可复用资料，但未在本版进行平台兼容验证。

## 资料与限制

每位至少两份实际阅读的实质材料，教授另有官方身份记录。资料记录见 [摄影家](references/sources/photographers.json)、[批评家](references/sources/critics.json)、[教授](references/sources/professors.json)。档案明确哪些是本人观点、机构解释和技能作者推导。已知研究缺口在个人档案末尾列出。

0.2.0新增31份实质正文，覆盖全部22位；现有93条来源记录，其中81条为实质材料。新增内容包括彩色与重编、童暦、Opticks、M/E、Human Spring、BONSAI、家庭拍摄，以及教授的具体研究／讲评实践。阶段差异、引语归属和未取得的全文分别保留，详见 [深化记录](docs/research-deepening.md) 与 [逐人变更映射](research/deepening-2026-10-15/change-map.json)。

作品网页目视属于有限抽样，见 [视觉抽查](references/visual-review.json)。没有通读全部摄影集，也没有观察原作印相；文字获取不能代替看图。可访问网页出现错误时仍需交叉核验，官方来源也不免于具体错误。

行为评估原始回应与人工核查见 [测试说明](tests/README.md)。初始固定测试图为原创合成场景；另有三张带来源及使用说明的 [真实照片](tests/real-fixtures/README.md) 作独立前后对照。它们可验证规则使用和证据边界，不能证明对真实作品集的长期评判效果。后续试用另记许可依据、模型及日期。

## 本地验证

Python 3.11或更高；结构检查和回归测试只用标准库，不需要 API 密钥。

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
```

CI执行同样命令。测试图已经随包附上；仅重新生成测试图时需要 Pillow。校验发现结构错误会以非零状态退出；它不自动证实来源内容或艺术判断。

首版的25项结构回归、搬移检查、独立复核和行为验证范围见 [交付验证记录](docs/validation.md)。GitHub Actions将在你发布仓库后运行；本地交付没有声称远端CI已执行或全局技能已安装。
