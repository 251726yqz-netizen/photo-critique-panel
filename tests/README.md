# 验证范围与复现

## 离线结构回归

```sh
python3 scripts/validate.py
python3 -m unittest discover -s tests -v
```

校验器关注可观察的包完整性：档案和来源映射、独立材料计数、教授身份记录、声明编号、中文I→R映射、相对路径与未完成内容。测试使用临时目录，故意制造来源重复、失效链接、缺档、错误日期、无效JSON等情况，确保校验确实拒绝坏包；不要求评论逐字匹配。

本版开发先运行测试，确认缺少校验器时失败，再实现并运行通过。中文紧邻I编号曾导致词界误判，另以回归测试证明修复。自动检查不识别来源语义真假、材料深度或审美正确性。

## 行为测试

输入固定为 [scenarios.json](scenarios.json) 及 [fixtures](fixtures/LICENSE.md)。基线评估器不读取技能；带技能评估器使用相同请求并读取技能／资料。两次原始回应分别保存到 results 目录。评估者不修改输入，也不自我评分。

场景覆盖三视角区别、顺序变化、作者陈述与画面落差、冒充／引语压力、图像内指令、低清／缺失文件、无目标修士申请。带技能阶段另做22席覆盖的实际输出检查。

另有 [真实场景](real-scenarios.json) 与 [三张真实照片](real-fixtures/README.md)，分别由新的独立评估者做无技能／带技能对照，两者只共享精确提示与图像输入。真实测试与合成测试分别保存，不能当作同一批输入。

另行补测已有但损坏的图片／PDF及官方申请年度／类别匹配；这些是带技能边界验证，没有配对基线，不能计为相对提升。

0.2.0资料深化另有 [四组覆盖22席的固定提示](deepening-scenarios.json)、[修改前后人工判定](results/deepening-assessment.md)和两份原回应。它比较现有Skill的资料版本，不是无Skill／有Skill对照；不得混算。所有精确提示、图片路径和名单一致，版本哈希另存。

由主维护者阅读回应并填写 [结果判定](results/assessment.md)，记录日期、模型可知范围、通过／部分／失败和实际证据。不将基线已经通过的行为写成技能带来的提升，不用结构测试替代模型行为验证。

## 重要限制

原始六张PNG为原创CC0程序生成场景，**不是实拍摄影或真实申请案例**。补充的JPEG是真实公开摄影，不是用户自己的申请作品。两组都没有原作印相、真实申请材料或录取结果。当前测试说明规则是否被使用，不证明长期稳定性、审美准确率或录取效果。

后续应增加作者许可的真实照片：模糊街景、技术清晰但表达薄弱的照片、纪实、摆拍肖像、自然作品，以及获准使用的完整申请作品集。真实“表达薄弱”也是人工评价，不应在文件名中当作客观标签。

每次复测保存：实际宿主模型／版本（不可知时如实标注）、输入图像及授权方式、日期、选定评委、精确提示、原始输出、人工判定。性能发生变化时再重复有关场景，不声称一次通过就普遍可靠。
