# 中文报告规范

## 材料登记

写明评审模式、所选席位、图片编号与顺序、实际查看的页码、作者说明、未知信息。开头一次标明：这是基于公开资料的 AI 分析视角。报告可供作者或第三方照片使用；作品作者归属只按提供信息说明。

## 逐位评论

每席通常120–220中文字，必要时加长。不能只列风格关键词。固定含义，允许自然行文：

1. **核心判断：**关于当前图像的一句结论，或“证据不足，保留判断”。
2. **图像证据：**P编号／页码＋位置＋可见关系。来源缺失时不写假观察。
3. **理念参考：**人物档案 I编号、来源ID及原始链接；若是机构解释，注明机构／作者。
4. **局限：**当前材料不能证明的事，或该视角的适用范围。
5. **建议：**一个动作及检查结果的方法；写成技能推导的建议。

全选默认顺序按 registry：10摄影家→2批评家→10教授。指定少数时保留索引顺序。相同图像证据可重复使用，但判断理由必须对应本席的 I/R。

## 共识和分歧

用小表呈现：议题、支持意见、不同意见、标准差异。不要写“大家认为”而实际只出现一位。综合建议引用席位和证据；少数意见不被平均或多数票删除。

## 三项优先行动

每项写：目前问题／机会 → 拍摄或编辑动作 → 如何检验 → 对应席位。学习练习、艺术表达和申请提交的优先级按任务目标排列；不制造第三项以填模板。

## 申请附录

独立列出官方提交要求：学校、课程、年度、类别、条款位置、核查日期、来源、材料满足／缺失／未核实。另列作品建议和可准备的面试问题。课程适配基于公开研究及课程资料；不预测导师接受或录取。

## 所用来源与覆盖说明

仅列本次实际用到的来源。资料库历史读取与本次招生核查分别写清。说明已评席位与待评席位、未读材料。若用户需要保存报告，生成本地 Markdown；不自动上传照片或发布报告。
